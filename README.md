# 🚀 GDG on Campus – RIT Hassan

### Learn. Build. Connect. Innovate.

Welcome to the official website of **Google Developer Groups (GDG) on Campus – Rajeev Institute of Technology, Hassan**.

Our website is designed to connect students with technology, innovation, and development opportunities. It provides information about technical workshops, hackathons, coding activities, events, and student community activities.

## 🌟 About the Project

GDG on Campus is a student developer community that encourages students to explore new technologies, improve their technical skills, collaborate on projects, and develop real-world solutions.

This website acts as a digital platform for students to discover events, explore activities, and become part of the developer community.

## ✨ Features

- 🏠 **Home:** Attractive landing page with GDG introduction.
- 👥 **About Us:** Information about the club and its objectives.
- 💻 **Activities:** Technical workshops, coding sessions, and project development.
- ⚡ **Events:** Information about technical events and CODESTORM 2026.
- 📝 **Join Us:** Student membership registration interface.
- 📱 **Responsive Design:** Supports mobile, tablet, and desktop devices.
- 🎨 **Modern UI:** Clean design with interactive elements.

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Alternatively, use the Live Server extension.
5. Explore the website.

No Node.js installation is required.

## 🌐 Deployment

This project can be deployed using GitHub Pages.

1. Upload all project files to a public GitHub repository.
2. Open repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select the `main` branch.
6. Select the `/ (root)` folder.
7. Click Save.

Your website will be published using GitHub Pages.
